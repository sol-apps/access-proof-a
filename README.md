# Access Proof A

A minimal internal demonstration that platform sign-in works: it shows the signed-in
person's display name and role in this app, and exercises one protected route and one
admin-only route that both refuse unauthorised callers on the server.

This is an acceptance-test app, not a production business tool. Every message it shows
is invented, it has no collections of its own, and it writes nothing anywhere.

Generated by the [Greenlight](https://greenlight.solhann.net) build wizard, and
delivered as a pull request rather than a deploy — a human approving that pull
request is what lets this app exist.

Merging it is also what ships it. A merge to `main` puts this repo live on its own
subdomain automatically, so the approval is the deploy; there is no separate release
step afterwards, and no way to reach production that skips the review.

- **Spec:** [`spec.json`](spec.json) — the capabilities, scopes and tier this app
  declares, agreed with the builder before any code was written.
- **Conventions:** [`AGENT.md`](AGENT.md) — node-free static frontend, PocketBase
  hooks, vendored design system.
- **CI:** every pull request is checked against `spec.json`. Code that contradicts
  its own spec does not merge.

## Routes

| Route | Who it answers | Otherwise |
| --- | --- | --- |
| `GET /api/proof/message` | any signed-in user of this app | `401` |
| `GET /api/proof/admin` | admins of this app (server-set `users.role`) | `403` for ordinary users, `401` unauthenticated |

## Running it locally

```bash
GREENLIGHT_IDENTITY_MODE=local pocketbase serve --publicDir . \
  --hooksDir ./pb_hooks --dir ./.pb_data --migrationsDir ./pb_migrations
```

Then open http://127.0.0.1:8090.

There is no identity provider locally, so the identity hook needs to be told that
explicitly: `GREENLIGHT_IDENTITY_MODE=local` skips provider configuration and leaves
password auth enabled, so you can make a local account and work. On prod the mode is
`production` — provisioning writes the app's OIDC configuration before the instance is
ever started, password auth is switched off, and the only way in is a grant.
